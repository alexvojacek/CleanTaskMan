# Changelog

## 0.7.0

- First GitHub release of CleanTaskMan. Download a per-user Windows installer or the portable ZIP.
- The title bar and Windows app metadata use the Clean Task Manager name. The About dialog credits Reed, Morgan, and Alex.
- Reformatted the C++ source and tests for readability and added build and contribution instructions.

The Performance views show live CPU, memory, disk, network, and GPU activity. Run new task, Services Start and Stop, and startup item controls are still in development.

The app and installer are unsigned. The **Replace Task Manager** option starts off. If you enable it, turn it off before uninstalling the associated copy. The installer preserves your settings and window placement files.

The release passed the native UI, telemetry, and settings checks and an install, reinstall, and uninstall test on Windows 11 x64.
